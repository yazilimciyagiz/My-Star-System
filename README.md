# My Star System

​Copyright (C) 2026 yazilimciyagiz

My Star System is a web-based, interactive 2D solar system simulator and editor built with HTML5 Canvas and JavaScript. It allows users to create, customize, and manage unique planetary systems with customized stars, planets, and orbiting moons in real time.

## Features

- Interactive 2D celestial body rendering on HTML5 Canvas
- Star creation with spectral types based on age classification
- Planet and moon system configuration
- Circular and elliptical orbit mechanics simulation
- Procedural planet surface generation with land and water ratios
- Multi-language UI support (English, Turkish, Spanish, Azerbaijani)
- LocalStorage integration for saving and loading custom systems
- Responsive viewport controls with pan and zoom interactions

## Technologies Used

- HTML5 / Canvas API
- CSS3 (CSS Variables, Animations, Responsive Design)
- JavaScript (Vanilla JS, LocalStorage API)

## Installation and Setup

1. Clone or download the repository:
   git clone https://github.com/yazilimciyagiz/my-star-system.git

2. Open index.html directly in any modern web browser or host it via a local web server.
